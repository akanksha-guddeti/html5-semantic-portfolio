# HTML5 Semantic Structure & Accessibility Portfolio

A responsive, multi-page personal portfolio website built using **HTML5 and CSS3**, following semantic markup, accessibility best practices, and SEO-friendly principles.

## 📌 Project Overview

This project demonstrates how to structure a personal portfolio using modern semantic HTML5 elements and accessible web design techniques. It includes dedicated pages for introduction, education, technical skills, projects, and contact information.

## ✨ Features

- **Semantic HTML5:** Uses `header`, `nav`, `main`, `section`, `article`, and `footer`.
- **Accessibility:** Skip-to-content link, ARIA labels, descriptive navigation, and keyboard-visible focus indicators.
- **Responsive Design:** Adapts to desktop and mobile screen sizes.
- **SEO Optimization:** Includes page titles, meta descriptions, viewport settings, and language attributes.
- **Accessible Contact Form:** Properly associated labels, required-field validation, and suitable input types.
- **Consistent Navigation:** Links connect all four portfolio pages.
- **Modern UI:** Clean layout, readable typography, and a professional dark theme.
